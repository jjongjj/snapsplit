# SplitForge 0.4.1

Cut a model into printable parts and join them with connectors (Blender 5.2 extension).
Sidebar (N) tab **SplitForge**.

- Cut stack (Draft) or one-click cuts (Easy): planes, drawn strokes, polylines (clicked points)
  and polygon cut-outs; Build never changes the original (parts in `SplitForge_Build_<object>`).
- Connectors: cylinder pins, tenons, dovetails, snap variants, custom meshes, separate dowels;
  distributed automatically or clicked onto the seam, each checked in 3D.
- Print checks with one-click fixes (transforms, millimeter units, normals, duplicates, holes).
- Export of all parts to STL/OBJ/FBX in millimeters.

Set the scene to Millimeters with Unit Scale 0.001 first (the **Fix** button in the panel does it).
Full guide: <https://github.com/jjongjj/snapsplit> (README.md).
